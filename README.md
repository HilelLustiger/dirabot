# 🏠 בוט חיפוש דירה

בוט טלגרם לקבוצה משותפת: קולט מודעות, מחלץ פרטים, מנהל סטטוסים בכפתורים ושולח סיכום בוקר.

## קבצים
| קובץ | תפקיד |
|---|---|
| `core.py` | DB, סטטוסים, קישורים, פענוח תאריכים. לא תלוי בטלגרם |
| `llm.py` | חילוץ פרטי מודעה ופענוח "מתי" חופשי (Claude Haiku) |
| `bot.py` | טלגרם: כרטיסים, כפתורים, פקודות, סיכום בוקר |

## התקנה (כ-15 דקות)

### 1. הבוט בטלגרם
1. ב-[@BotFather](https://t.me/BotFather): `/newbot`, שמרו את הטוקן.
2. **חובה:** `/setprivacy` ← בחרו את הבוט ← `Disable`. בלי זה הבוט לא רואה קישורים בקבוצה.
3. צרו קבוצה לשניכם. **רק אחרי שלב 2** הוסיפו אליה את הבוט.

### 2. Railway
1. העלו את הקבצים ל-repo ב-GitHub וצרו שירות חדש ממנו.
2. **Volume:** בשירות ← Settings ← Volumes ← הוסיפו Volume עם mount path ‏`/data`.
   בלי זה כל deploy מוחק את כל הדירות.
3. **Variables:**
   - `TELEGRAM_TOKEN` = הטוקן מ-BotFather
   - `ANTHROPIC_API_KEY` = מפתח מ-console.anthropic.com
   - `ALLOWED_CHAT_ID` = השאירו ריק בינתיים
4. Deploy. `railway.json` כבר מגדיר replica אחת והפעלה מחדש אוטומטית. לא צריך דומיין או port.

### 3. נעילה לקבוצה שלכם
1. כתבו `/chatid` בקבוצה. הבוט יחזיר מספר שלילי, למשל `-1001234567890`.
2. הכניסו אותו ל-`ALLOWED_CHAT_ID` ב-Railway. השירות יעלה מחדש לבד.
3. כתבו `/help` בקבוצה. אם הבוט עונה, אתם באוויר.

### משתנים אופציונליים
- `DIGEST_TIME` (ברירת מחדל `08:30`, שעון ישראל)
- `LLM_MODEL` (ברירת מחדל `claude-haiku-5-5`)
- `DB_PATH` (ברירת מחדל `/data/apartments.db`)

## שימוש
- **מודעה חדשה:** שלחו קישור לקבוצה, רצוי עם הטקסט של המודעה באותה הודעה. אפשר גם Forward.
  מפייסבוק כדאי להעתיק גם את הטקסט, כי אי אפשר לקרוא אותו מהקישור.
- **סטטוס:** כפתורים בכרטיס. כל שינוי מעדכן את הכרטיס ושולח שורת לוג לתחתית הצ'אט.
- **קבענו:** הבוט שואל "מתי?". עונים ב-Reply: `ראשון 18:00`, `מחר ב-6`, `3.11 17:30`.
- **הערה:** Reply לכרטיס (או לכל הודעה של הבוט על הדירה). הבוט מגיב ב-👍.
- **השלמת פרטים:** Reply לכרטיס עם טקסט המודעה.
- **תיקון פרטים:** כפתור "✏️ תיקון פרטים" בכרטיס, או Reply לכרטיס עם שורות `שדה: ערך`
  (כתובת, שכונה, עיר, מחיר, חדרים, איש קשר, טלפון; `-` מוחק שדה), או במילים: `תיקון: זה ברמת גן`.
- **הודעת עזרה נעוצה:** הבוט שולח ונועץ אותה לבד בעלייה, ומעדכן אותה כשהיא משתנה. `/help` שולח ונועץ מחדש.
  בקבוצה הבוט צריך להיות מנהל עם הרשאה לנעיצת הודעות.
- כל הודעה אחרת בקבוצה: הבוט מתעלם, אפשר לדבר רגיל.

### מסלול הסטטוסים
```
חדשה → דיברנו → קבענו → ראינו → ❤️ רוצים
                                 ↘ ❌ דחינו
📵 לא עונה: מכל שלב פתוח, וחזרה ממנו למסלול
❌ דחינו:   מכל שלב פתוח
↩️ החזר לטיפול: מ"רוצים"/"דחינו" חזרה לשלב הקודם
```

### פקודות
| | |
|---|---|
| `/open` | כל מה שפתוח, לפי סטטוס |
| `/week` | ביקורים בשבוע הקרוב |
| `/all` | הכל, כולל מה שנדחה |
| `/card 12` | מקפיץ את כרטיס 12 לתחתית |
| `/digest` | סיכום עכשיו |
| `/export` | שולח לקבוצה קובץ גיבוי של ה-DB |

### סיכום בוקר
נשלח רק אם יש בו תוכן: ביקורים היום ומחר, ביקורים שעברו בלי עדכון (עם כפתורים),
דירות חדשות בלי מגע יומיים, "לא עונה" יותר מיומיים, ו"ראינו" בלי החלטה יותר מיומיים.

## הרצה מקומית לבדיקה
```bash
pip install -r requirements.txt
export TELEGRAM_TOKEN=... ANTHROPIC_API_KEY=... ALLOWED_CHAT_ID=...
python bot.py
```
אל תריצו מקומית ובמקביל ב-Railway: טלגרם מחזיר Conflict כששני מופעים עושים polling.
